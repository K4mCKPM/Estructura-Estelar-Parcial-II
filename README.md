# Estructura-Estelar-Parcial-II
Código y datos usados para la solución del parcial 2 de la materia de Estructura Estelar.

Los códigos de Python son de autoría mía, los datos encontrados en ['Jorgen Christensen.txt'](Jorgen%20Christensen.txt) son obtenidos del siguiente link:
[Solar models](https://users-phys.au.dk/jcd/solar_models/) By: Jørgen Christensen-Dalsgaard

El código ['Jorgen Christensen.py'](Jorgen%20Christensen.py) es usado para la primer parte del parcial, donde se usan los datos de 'Jorgen Christensen.txt'
para calcular la masa encerrada en un radio r, así como para calcular la energía potencial gravitatoria del sol

El código ['Cota superior.py'](Cota%20superior.py) es usado para la segunda parte del parcial, en donde se calculan las curvas de
cotas superiores para la fracción parcial de la presión por radiación respecto a la razón entre la masa de la estrella y la masa
solar.
